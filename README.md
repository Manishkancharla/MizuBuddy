# MizuBuddy
MizuBuddy is a water potability prediction and analysis system developed in Python. It uses nine measured physicochemical properties to classify a sample as potable or nonpotable. The inputs are pH, Hardness, Solids, Chloramines, Sulfate, Conductivity, Organic Carbon, Trihalomethanes and Turbidity. The supplied dataset contains 3,276  samples
